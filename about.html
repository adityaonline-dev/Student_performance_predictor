MODEL OVERVIEW

Random Forest Regression

Random Forest trains a collection of decision trees on varied samples of the training data, then averages their predictions. It can learn non-linear patterns and does not require features to be standardized for this project.

How to read these

MAE and RMSE are score-error measures, so lower values are generally better. R² compares the model with a simple mean-baseline predictor; it can be negative if performance is poor.

ⓘ
Important limitation

The supplied data is synthetic and based on an illustrative formula. The displayed metrics only show that the code runs; they do not demonstrate reliable prediction for real students. Use a documented dataset and validate carefully before drawing conclusions.
